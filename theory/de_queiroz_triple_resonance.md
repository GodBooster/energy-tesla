# Потрійний резонанс де Кейроза: цілочисельні умови k:l:m і повний перенос енергії

**Джерело:** Antonio Carlos M. de Queiroz, "Magnifier Performance Using Multiple Tuned Coils", доповіді з 2001–2010, та Denicolai M. "Optimal performance for Tesla transformers", Rev. Sci. Instrum. 73(9), 2002.

**Призначення:** дати замкнені формули для проєктування трансформатора Тесла з 3 контурами (магніфікатор), де перенос енергії з первинного у вихідний (третій) контур повний за мінімальну кількість циклів. Це безпосередньо застосовується в нашому Етапі 2.

---

## 1. Дві катушки vs три катушки

Стандартний Тесла-трансформатор має 2 котушки — первинну (Lp, Cp) і вторинну (Ls, Cs з Top-load). Денікольї показав, що повний перенос енергії з C1 на C2 можливий при двох умовах:

1. **Однакові резонансні частоти:** $\omega_1 = \omega_2$, тобто $L_p C_p = L_s C_s$
2. **Дискретний коефіцієнт зв'язку k**, який визначається з таблиці цілочисельних співвідношень — основний (a:c)=(1:2) дає k=0.6, повний перенос за 1 цикл; (3:4) дає k=0.28, перенос за 2 цикли; ...

**Магніфікатор Тесла** — 3 котушки. Первинна (Lp), вторинна (Ls) і "extra coil" (Le) — окрема резонансна спіраль, що працює як медленноволновий хвилевід (V_axial ~ 1–10% c). Перенесення енергії стає каскадним: Lp → Ls → Le. При правильному виборі параметрів виходить вища ефективна напруга на верхньому кінці Le при меншому коефіцієнті зв'язку Lp-Ls (безпечніше для діелектричного пробою).

---

## 2. Математична модель потрійного резонансу

Розглянемо систему трьох зв'язаних LC-контурів без втрат. Рівняння руху для зарядів $q_1, q_2, q_3$:

$$\begin{aligned}
L_1 \ddot q_1 + \frac{q_1}{C_1} + M_{12} \ddot q_2 &= 0 \\
L_2 \ddot q_2 + \frac{q_2}{C_2} + M_{12} \ddot q_1 + M_{23} \ddot q_3 &= 0 \\
L_3 \ddot q_3 + \frac{q_3}{C_3} + M_{23} \ddot q_2 &= 0
\end{aligned}$$

де $M_{12} = k_{12}\sqrt{L_1 L_2}$, $M_{23} = k_{23}\sqrt{L_2 L_3}$. Зазвичай немає прямого зв'язку 1-3 (далеко).

Власні частоти системи $\omega_k$ визначаються характеристичним рівнянням 6-го степеня (відносно $\omega^2$). При узгодженості $\omega_1=\omega_2=\omega_3=\omega_0$ ця система має три моди:

$$\omega_a, \omega_b, \omega_c$$

де $\omega_b \approx \omega_0$ (центральна) і $\omega_a, \omega_c$ розщеплені. Для повного переносу енергії з C1 на C3 за час T необхідно, щоб усі три моди мали цілочисельні частоти в одиницях $1/T$:

$$\omega_a T = a \pi, \quad \omega_b T = b \pi, \quad \omega_c T = c \pi$$

де $a < b < c$ — додатні непарні цілі числа з умовою $b = (a+c)/2$.

---

## 3. Формули де Кейроза

Введемо нормовані параметри:
$$x = \omega_a/\omega_0, \quad y = \omega_c/\omega_0$$

де $\omega_0$ — спільна резонансна частота окремих контурів. Тоді цілочисельні умови дають дискретні набори $(a,b,c)$:

| a | b | c | Циклів до повного переносу | k_12 | k_23 |
|---|---|---|----------------------------|------|------|
| 1 | 2 | 3 | 1.0 | 0.600 | 0.600 |
| 1 | 3 | 5 | 1.5 | 0.882 | 0.882 |
| 3 | 4 | 5 | 2.0 | 0.280 | 0.280 |
| 5 | 6 | 7 | 3.0 | 0.180 | 0.180 |
| 7 | 8 | 9 | 4.0 | 0.133 | 0.133 |

(Таблиця для випадку симетричного $k_{12} = k_{23}$; асиметричні випадки розширюють набір.)

Загальна формула для симетричного випадку:
$$k = \frac{c^2 - a^2}{c^2 + a^2}$$

де $c = a + 2$ для непарних трійок $(a, a+1, a+2)$. Це дає послідовність k = 0.6, 0.385, 0.28, 0.218, 0.18, 0.152, 0.133, ...

---

## 4. Що означає "повний перенос за N циклів"

Повний перенос — це момент, коли вся енергія з $C_1$ передана у $C_3$ (на проміжний $C_2$ припадає 0). Для $N=1$ (одноциклова система) це найшвидше, але вимагає k=0.6 — дуже щільного зв'язку, який створює проблеми діелектричного пробою.

Практично, рекомендований діапазон:
- **k = 0.28 (2 цикли)** — оптимум для невтратної системи; 30 см зазор між Lp і Ls безпечний при 100 кВ.
- **k = 0.18 (3 цикли)** — для систем з втратами в розряднику 10–20%.

Для **демпфованої системи** (реальної, з втратами) Денікольї підкреслює: **критично досягти максимальної напруги у мінімальний час**. Тобто менше k бажано тільки якщо критично уникнути пробою; в інших випадках обираємо k якомога вище.

---

## 5. Іскровий розрядник: нелінійна модуляція

Усі формули вище — для лінійної системи без втрат. Реальний Тесла-трансформатор має іскровий розрядник, який:
1. Замикає первинний контур, дозволяючи перенос Lp → Ls.
2. Розмикає його, коли напруга на C1 падає нижче деякого порогу (V_quench).
3. Дозволяє вторинному контуру вільно дзвонити з квазі-Q-фактором.

Це призводить до **break-out** (стримерний розряд) при високих напругах і "звільненої осциляції" вторинної частини. Енергетично пристрій не отримує бонус — лише перерозподіл за модами.

**Параметрична інтерпретація:** іскровий розрядник можна розглядати як перемикач, що скачкоподібно змінює структуру системи з 1-контурної (заряд C1) на 3-контурну (резонансний обмін). Це не безперервна параметрична накачка (як у класичному параметричному підсилювачі з варактором) — це переключення станів.

## 6. Практичні наслідки для Етапу 2

Для нашої катушки (Ns=1600, Rs=57 мм, Hs=570 мм, Ctl≈20 пФ → Frs≈76 кГц):

1. **Налаштовуємо T=1:** Lp · Ctc = Ls · Ctl, отже Lp = Ls·(Ctl/Ctc) = 0.216 H · (20 пФ / 17.5 нФ) ≈ 247 мкГн.
2. **Обираємо k = 0.28** як оптимальний.
3. **Геометрично:** для плоскої первинки Ø6 мм трубка, ~9 витків, зовнішній Ø ~400 мм → Lp ≈ 250 мкГн.
4. **Зв'язок налаштовуємо** регулюванням висоти первинки відносно вторинної (висуваємо/опускаємо). Для k=0.28 первинка зазвичай 1–3 см вище основи вторинної.
5. **Тонке налаштування T=1** виконується **переміщенням відводу** на первинці (це найпрактичніший спосіб за Денікольї).

## 7. Симуляція в SPICE

Базова модель — три зв'язані LC-контури з спільним магнітним зв'язком. У LTspice:

```
* Triple-resonance Tesla (de Queiroz) — schematic outline
.param L1=247u L2=216m L3=0   ; 2-coil case for now
.param C1=17.5n C2=20p C3=0
.param k=0.28
.param freq=76k

L1 n1 0 {L1}
C1 nin n1 {C1}
L2 n2 0 {L2}
C2 ntop n2 {C2}
K12 L1 L2 {k}

* Spark gap (simplified piecewise linear)
S1 nin npri SPARK SW
.model SW SW(Ron=0.01 Roff=1Meg Vt=8k Vh=2k)

* HV NST source
V1 npri 0 SIN(0 15kV 50)

* Ground for top load
R_ground ntop ntop_g 1
C_top_g ntop_g 0 1f

.tran 0 100m 0 1u
.end
```

Це базова форма. Реальна модель з втратами в шунтах, паразитними ємностями і скін-ефектом — окрема ітерація. Реалізована буде в `simulations/02_tesla_coil/`.

## 8. Extra-coil (Magnifier): формули для розрахунку за Стребковим

**Джерело:** Стребков Д.С., Ізіляєв І.Р. "Методика розрахунку резонансного ВВ-трансформатора", Досягнення науки і техніки АПК №1-2012; та Стребков Д.С. "КАТ ТЕСЛИ" (2007).

Extra-coil (L3 або Le) — чвертьхвильовий спіральний хвилевід. Відрізняється від звичайної котушки тим, що є **хвилеводом** з уповільненою фазовою швидкістю, а не зосередженою індуктивністю.

### Параметри Colorado Springs (Тесла, 1899)
| Параметр | Значення |
|---|---|
| L1 (первинна) | 27 мкГн |
| R1 @ 90 кГц | 8 Ом |
| C1 (MMC) | 0.12 мкФ |
| f0 | 88.5 кГц |
| λ0 | 3390 м |
| I1 пік | 10000 А |
| VC1 | 150 кВ |
| L2 (вторинна) | 9 мГн, N2=20 витків |
| VL2 | 3 МВ |
| Extra-coil L3 | D=2.515 м, H=2.44 м, N3=95, d_wire=1.25 мм, L_wire=1500 м |
| C3 (сферична) | 300 пФ |

### Ключові формули extra-coil

**Velocity factor (коефіцієнт уповільнення):**
$$K_u = \frac{\sqrt{D \cdot t}}{\pi \cdot \lambda_0}$$
де D — діаметр спіралі, t — крок намотки, λ₀ — довжина хвилі у вільному просторі.
Для Colorado Springs: Ku = 0.00179 (хвиля уповільнена в ~560 разів).

**Характерний імпеданс хвилеводу:**
$$Z_0 = \frac{60}{K_u} \left[\ln\frac{4H}{D} - 1\right]$$
Для Colorado Springs: Z₀ = 11732 Ом (або 94156 Ом у другому варіанті статті).

**Коефіцієнт втрат (на довжину H):**
$$\alpha l = \frac{H}{Z_0} \sqrt{\frac{\pi f_0 \rho}{d_w}}$$
де ρ — питомий опір міді, dw — діаметр дроту.
Для Colorado Springs: αl = 0.00445 Нпр.

**Напруга на виході extra-coil:**
$$V_{out} = \frac{V_{in}}{\alpha l}$$
де V_in = VL2 = 3 МВ → V_out = 3·10⁶/0.00445 = **674 МВ** (теоретично).
Практично досяжно: 20–100 МВ (обмежується ізоляцією та розрядами).

### Наслідки для нашого стенду (80.5 кГц)

Для нашої вторинки VL2 ≈ 150–500 кВ (реалістично).
Якщо побудувати extra-coil з тими самими αl ≈ 0.004:
- V_extra_out = 150 кВ / 0.004 = **37 МВ** — теоретично
- Практично: 1–5 МВ з урахуванням діелектричного пробою повітря

Extra-coil для нашого стенду: λ₀ = c/f₀ = 3·10⁸/80500 ≈ 3730 м; λ/4 = 932 м.
При Ku ≈ 0.002: фізична довжина хвилеводу H = λ/4 · Ku = 932·0.002 ≈ **1.86 м**
(досяжна висота котушки для домашнього стенду!)

## 9. Майбутні розширення

- 3-катушковий магніфікатор: додаємо L3, C3 з k_23, налаштовуємо за таблицею (a,b,c) = (3,5,7) або (1,3,5).
- Симуляція ефекту заземлення: додаємо до моделі модель "землі" як R_g + L_g + C_g та (можливо) джерело атмосферного потенціалу. Це для перевірки A/B/C сценарію в SPICE.
- Параметричне підсилення: модель з модульованою L (накачка) — для перевірки, чи дає вона COP > 1 при правильно фазованій модуляції (за стандартною теорією — ні для електричної потужності).
