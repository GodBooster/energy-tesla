## 1. Фізична модель глобального електричного кола

Атмосферне електрство (АЕ) — реновативне ДЕ в повному сенсі:

| Параметр | Значення |
|---|---|
| Напруга іоносфера–земля | **350 кВ** |
| E-поле у поверхні (ясна погода) | **100 В/м** |
| E-поле під час грози | **40–100 кВ/м** |
| Одночасних гроз | 1500–2000 |
| Загальний струм ГЕЛ | 800–1500 А |
| Заряд хмари (середнє) | 30 кДж |
| Тривалість грозового стану (Росія) | 40–60 год/рік (південь: 80–100 год/рік) |
| Опір шару обміну атмосфери | 1.3 × 10¹⁷ Ом |

Глобальне електричне коло (ГЕЛ): замкнена система — провідні шари нижньої атмосфери + земна кора, грозові зони = генератори ЕРС. Земля і іоносфера — обкладки сферичного конденсатора.

## 2. Лабораторна установка Стрєбкова (рис. 2.38–2.40)

**Принцип роботи:**

```
Атмосфера → Активний молнієвловлювач (АМП)
         → Накопичувальна ємність C (заряджається від АМП)
         → Розрядник P (спрацьовує при напрузі пробою)
         → Конічна резонансна котушка L (нижній кінець = заземлення)
         → На верхньому кінці L з'являється ВИСОКА НАПРУГА
         → Ця напруга ініціює наступний розряд від хмари → АМП (цикл)
```

**Параметри конічної котушки:**
- L = 27 мГн
- Q = 60
- f_res = **310 кГц**
- Намотана дротом ПВВ-1, переріз жили 1 мм²
- Вертикальне розташування на 6 ізоляторах

**Параметри розрядника:** регульований зазор 0–3 мм (точність 0.1 мм)

**Лабораторні результати:**
- Вхідна напруга (імітація хмари): 10 кВ від ДПН на металеву сферу
- Напруга пробою на розряднику: **40 кВ**
- Вихідна напруга на верхньому кінці котушки: **300–350 кВ**
- Довжина іскри: **понад 1 м**
- Форма сигналу зі зв'язаної котушки: затухаючі синусоїди
- Частота коливань: **250–350 кГц**
- Тривалість пачки: 200–500 мкс
- Енергія однієї пачки: **~0.1 Дж**
- Частота повторення пачок: до **50 Гц**

**Максимальна розрахункова середня потужність:** 0.1 Дж × 50 Гц = **5 Вт** (в лабораторних умовах з 10 кВ ДПН).

## 3. Система збору АЕ без грози (рис. 2.46)

Для ясної погоди — масив вертикальних дротів:

**Принцип:** геомагнітне поле Землі + рух носіїв в атмосфері → мала ЕРС на вертикальному провіднику. Формула ЕРС: ΔU = E_атм × L_дроту, де E_атм ≈ 100 В/м, L = 50 мм → ΔU ≈ **0.5 В** на нитку.

**Типовий струм:** I ≈ **0.0001 А** (100 мкА) через кожну нитку.

**Потужність на нитку:** P = 0.5 × 0.0001 = **50 мкВт**

**Масив 999 ниток паралельно:**
- Сумарний струм: 999 × 0.0001 = **0.1 А**
- Напруга: 0.5 В
- Потужність: **50 мВт** максимум

Через електронний комутатор сигнал перетворюється на ВЧ імпульси і передається однопровідною резонансною лінією до навантаження.

**Критична оцінка:** 50 мВт від масиву 1000 дротів у ясну погоду — **практично нікчемно** для живлення будь-якого реального навантаження. Це не джерело "вільної енергії".

## 4. Що дає АЕ реально корисного

| Режим | Потужність | Практичність |
|---|---|---|
| Ясна погода, масив ниток | 50 мВт / 1000 дротів | Майже нуль |
| Передгрозовий (E-поле × 10–100) | 0.5–5 Вт | Мала, але вимірювана |
| Грозовий (прямий удар) | кДж за мкс, 1–10 ГВт пікова | Реально, але некерована |
| Однопровідна резонансна лінія з НВЧ | до 20 кВт, 1.7 км (§4.4) | **Реально перевірено!** |

**Головний технологічний продукт Стрєбкова — не збір АЕ, а однопровідна передача потужності** (§4.4). Збір АЕ — додаткова тема, поки не вийшла за межі лабораторії.

## 5. Висновки для проєкту (A/B тест заземлення)

### Чому заземлення НЕ "додає активну потужність" через механізм АЕ:

1. **Денситет АЕ в ясну погоду надто малий.** Навіть з ідеальним заземленням-антеною, потужність від E_атм=100 В/м через котушку Тесла з нашими параметрами дасть мікровати, не вати. Різниця між A (заземлено) і C (без заземлення) в ясну погоду за рахунок АЕ: **менше 1 мВт** → нижче порогу чутності нашої вимірювальної установки.

2. **Грозовий режим непридатний для керованого A/B тесту.** Випадкові удари унеможливлюють статистичну чистоту.

3. **Що заземлення ДІЙСНО робить в котушці Тесла:**
   - Встановлює потенційну **опорну точку** для стоячої хвилі (вузол напруги).
   - Змінює розподіл ємності "котушка–земля" → зсуває f_res.
   - Забезпечує **зворотний шлях для струму** у системі Тесла (вузол струму).
   - Без заземлення котушка "висить" і E-поле навколо неї симетричне — менша взаємодія з середовищем.

4. **Якщо A/B тест покаже різницю >3σ:** це буде NOT механізм АЕ, а або:
   a) Зміна Q (заземлення зменшує або збільшує ефективні втрати).
   b) Параметрична накачка телуричними струмами (дивись §1.14 нижче).
   c) Вимірювальний артефакт (зсув cos(φ) при зміні топології).

### Рекомендація для протоколу:
- Проводити A/B тест **у ясну погоду** (унеможливити АЕ як змінну).
- Окремо — передгрозовий тест (записувати E-поле метеодатчиком одночасно).
- Записувати опір заземлення R_gnd перед кожним прогоном (цільове <10 Ом).

## 6. Схема пристрою (для відтворення у Етапі 2)

Якщо хочемо перевірити саме атмосферне збирання (не основна задача):

```
Антена (вертикальний дріт 2–5 м)
  ↓
Резонансна котушка L (f_res ≈ 88.5 кГц, наша вторинна)
  ↓
Накопичувальний конденсатор C (10–100 нФ, 10 кВ)
  ↓
Розрядник P (зазор 1–3 мм, регульований)
  ↓
Калориметр (резистор у воді)
  ↓
Земля (заземлення ≤10 Ом)
```

Це ПАСИВНА схема. Очікувана потужність в ясну погоду: <1 мВт. Під час грози: небезпечно без захисту від прямого удару (запобіжники, розрядники 30 кВ).
