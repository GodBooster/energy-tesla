## 3. Компоненти (з схем і форумних джерел)

### 3.1 Силові транзистори
- **IRFP260N** × 2 (або 4 у двосиметричній A1R1)
  - N-канальний MOSFET: Vds = 200 V, Id = 46 A, Rds_on = 40 мОм
  - Включення: push-pull (один — верхнє плече, другий — нижнє)
  - Режим: відсічка / насичення (ключовий, не лінійний)
  - Конфігурація A1R1: дві пари, дзеркально-симетрично

### 3.2 Драйвер
- **IR2153** (самозбудний напівмостовий драйвер, Vcc 10-20 V)
  - Внутрішній генератор: f = 1.4/(R_T × C_T)
  - Фіксований dead-time ~1.2 мкс
  - Застосування: керує верхнім і нижнім IRFP260N без трансформатора розв'язки
  - **Ключова умова схеми "dual IR2153":** f(L1) = 2 × f(L5) → цілочисельне відношення частот, відповідає умові (a,b,c) де Кейроза

- **TL494** (альтернативний драйвер)
  - ШІМ-контролер 5–300 кГц
  - Використовується для точного регулювання скважності і частоти
  - Переваги: регулювання рівня живлення, захист від перенавантаження
  - У блок-схемі: стоїть перед IRFP260N через трансформатор розв'язки

### 3.3 Діоди
- **UF4007**: ультрашвидкий 1 A / 1000 V (gate захист, bootstrap)
- **UF5408**: ультрашвидкий 3 A / 1000 V (вихідний випрямляч)
- **TV flyback diode** (безіменний): HV-діод з секцій рядкового трансформатора
  - Зворотна напруга ~20-50 кВ
  - Застосування: випрямлення ВВ-сигналу з вторинної котушки для сигналу ОЗ

### 3.4 Конденсатори
- **1000 мкФ / 50 V** × 2 (основне живлення)
- **MMC первинного контуру** (C1): ~10-100 нФ / ~1-5 кВ
- **Ємність вторинного контуру** (C4 або паразитна тороїда)

### 3.5 Індуктивності
- **L1** — первинна котушка ТТ (плоска спіраль або гвинтова, мала індуктивність, мале R)
- **L2** — вторинна котушка ТТ (Ns >> Np, висока Q)
- **L3** — додатковий дросель у контурі зворотного зв'язку або другий резонансний контур
- **L4** — чвертьхвильовий резонатор (провід або шина, довжина = λ/4 або кратне)
- **L5** — у схемі "dual IR2153": другий резонансний контур, f(L5) = f(L1)/2

## 4. Цілочисельні частотні відношення — зв'язок із де Кейрозом

Схема "BTG dual IR2153" явно містить напис:

> **"частота на L1 повинна бути 2× більше ніж на L5"**

Це точно відповідає умові потрійного резонансу де Кейроза для (a=1, b=2, c=3):
- k = (c²-a²)/(c²+a²) = (9-1)/(9+1) = 0.800
- При цьому ω₁ : ω₂ : ω₃ = 1 : 2 : 3

**Або (3,4,5) для нашого основного варіанту:**
- f₁ = f₀ × 3, f₂ = f₀ × 4, f₃ = f₀ × 5
- k = 0.280

**Наслідок:** Romancorp БТГР — це електронна реалізація тієї самої де-Кейроз-топології, але з транзисторним генератором замість іскрового розрядника.

## 5. Механізм зворотного зв'язку (гіпотетично)

На основі аналізу схем (без верифікованих вимірювань):

```
Вторинна котушка L2 → ВВ-напруга → TV flyback diode → випрямлення →
дільник напруги R1/R2 → порогова схема (або просто: транзистор-ключ) →
вимкнення MOSFET-стартера (відключення батареї) → схема працює 
від зворотного зв'язку
```

**Невирішені питання:**
1. Яка саме фаза ВВ-сигналу використовується для ОЗ?
2. Чи є у схемі фазовий коректор? (Мельниченко говорить: потрібно)
3. Як стабілізується амплітуда? (Розрядник = обмежувач — у Капанадзе; у БТГР?)

## 7. Критична оцінка

**Що інженерно коректно:**
- Push-pull driver для первинної котушки ТТ — стандартна практика (краще за однотактний)
- IR2153 для частот 20–200 кГц — відпрацьований підхід
- IRFP260N — прийнятний вибір (але є кращі для ВЧ: SiC MOSFETs)
- Цілочисельне відношення частот — правильний спосіб підвищення ефективності передачі енергії між котушками

**Що не верифіковано:**
- Зворотний зв'язок = самозапитка: жодне вимірювання у незалежних умовах не підтверджено
- "TV flyback diode на gate → вимкнення стартера" — чи надходить справжня активна потужність чи лише наведений сигнал?
- Роль L4 (λ/4): якщо L4 = антена, то є реальний вихід Герцівської енергії (є! але тоді ефективність < 1 щодо вхідної)

**Три незмінні питання:**
1. Яка реальна P_input (від батареї, вирахувано за відключення стартера)?
2. Яка реальна P_output (калориметр)?
3. COP = P_out/P_in < 1, = 1, або > 1?

## 8. Що реалізувати в SPICE

Файл: `simulations/03_kapanadze/romancorp_btgr.cir`

**Мінімальна модель для перевірки гіпотези:**
- Push-pull джерело напруги (квадратна хвиля) замість реального MOSFET-драйвера
- Первинний LC-контур L1+C1
- Магнітна пов'язка k з вторинним контуром L2 (де-Кейроз)
- Вторинний контур L2+C2 (тороїдна ємність)
- L4 як резистивне навантаження або відкрита лінія
- Rload на вторинній котушці (еквівалент навантаження)
- Для A/B-тесту: Rground = 5 Ω (A) або 1 МОм (C)
- Вимірювання: P_input = V_driver × I_L1; P_output = I_Rload² × Rload

**Що НЕ моделюємо в першій ітерації:**
- Реальний IR2153 (замінюємо прямокутним джерелом V_drv)
- Нелінійний TV flyback diode (замінюємо ідеальним діодом + RC-ланцюг)
- Реальна MOSFET-характеристика (замінюємо ключем SW)
