## 1. Підтвердження резонансної частоти 88.5 кГц

**Знайдено напряму в тексті (сторінка ~28 червня 1899):**

Тесла розраховує вторинну котушку з 20 витками при 139 футів кола на виток:
- Довжина дроту: A = 139 × 20 = 11,120 футів = **3,389 м**
- λ/4 = 2,780 футів = **847 м**
- Власна резонансна частота: f = c/(4 × 847) = **88,500 Гц ≈ 88.5 кГц** ✓

Тесла явно записує: `n = 90000 приблизно`, потім з додаванням кулі Ø38 см:  
`з коефіцієнтом 17/18.11, 17/18.11 × 93460 = 88000 приблизно` → **88 кГц** (без кулі — 93.5 кГц, з кулею — 88 кГц).

**Це незалежне підтвердження** числа з аналізу Стрєбкова. Стрєбков правильно реконструював параметри Colorado Springs.

## 2. Параметри вторинної катушки (реальні, не розрахункові)

З щоденника (вересень–жовтень 1899):

| Параметр | Значення |
|---|---|
| Кількість витків | 36 (основна конфігурація) → потім 20 витків |
| Крок намотки нижніх витків | 1" (≈ 25 мм) |
| Крок намотки верхніх витків | 2.5" (≈ 63 мм) — збільшений для тримання напруги |
| Дріт | No. 10 AWG (Ø 2.59 мм, мідний) |
| Каркас | Конічний або циліндричний, діаметр → не завжди чіткий через OCR |
| Добавочна котушка | 106 витків No. 10, Ø 8'3" = 251.46 см, висота 7'10" = 238.76 см |

**Добавочна котушка (extra coil)** — вимірювання 1 листопада 1899:
- 106 витків (реально 105+1 ненатягнутий)
- Діаметр каркасу 8'3" = **251.46 cm**
- Висота 7'10" = **238.76 cm**
- Площа перетину S = π×d²/4 = 49,662 кв. см
- Розрахована L = 12.5664 × N² × S / l = **0.029369 Гн = 29.4 мГн**
- Вимірюване: E/I = 18.13, R = 2.664 Ом → L = √((E/I)² − R²) / ω

**Порівняння зі Стрєбковим:**
Стрєбков дає для Colorado Springs: D = 2.515 м, H = 2.44 м, N = 95 витків.  
OCR-дані: D = 2.51 м, H = 2.39 м, N = 106 витків.  
→ Це дещо інший варіант котушки (Тесла переробляв конфігурацію). Числа Стрєбкова відповідають **більш пізньому** варіанту (95 витків, грудень 1899).

## 3. Стоячі хвилі в Землі: ключовий експеримент

З щоденника (вересень 1899, сторінка 194+):

> "9 вересня. Проводили експерименти зі стоячими хвилями. Точна відстань від пластини заземлення до вершини котушки склала 1938 футів."

> "...Земля виступала у ролі **вузлової зони** [для стримерів]."

Тесла підключає вторинний контур і добавочну котушку (схема 2), спостерігає:
- Стримери від кулі **уникали** громовідводів (заземлених), тобто йшли до незаземлених провідників → **Земля = вузол потенціалу** для цієї конфігурації.
- Коливання добавочної котушки **уповільнені** порівняно із вторинним контуром.
- Гармоніки в заземлюючому проводі від кулі **не домінували**.

**Висновок Тесли (серпень 1899, пряма цитата OCR):**
> "Прийшов до висновку, що опір заземлення був всі ще занадто великим [зі стандартним громовідводом]. Необхідно провести дослідження."

Тесла буре 2 метри у землю і засипає коксовою крихтою — **саме той метод, який наш план передбачає для Етапу 2**.

## 4. Головний підтверджений результат: Земля = провідник

Щоденник, серпень–вересень 1899:

> "Отримали свідчення на користь дослідження **стоячих хвиль у Землі**. Прийшли до висновку, що опір заземлення був занадто великим."

> "Не маю сумнівів, що вода легко проходить крізь ґрунт..."

Тесла задокументував:
1. Земля проводить ВЧ-струми (90–215 кГц), але з нетривіальним опором.
2. Опір заземлення критично впливає на ефективність.
3. Зволоження землі + вугільні добавки = стандартний метод Тесли.

Ключова числова оцінка:
- Первинний опір заземлення (сухий ґрунт): **2400–2960 Ом**
- Після 30 хвилин зволоження: **падає кратно**
- При ідеальному заземленні — систематичний зсув вузлів стримерів.

## 6. Що Colorado Springs Notes додає до нашого проєкту (порівняно з тим, що ми вже знали)

### Підтверджено:
- **f = 88.5 кГц** — не цифра зі Стрєбкова, а фактичне значення з оригіналу Тесли.
- Extra-coil: Tесла його реально будував і тестував (жовтень–грудень 1899).
- Заземлення — критичний параметр, досліджувався систематично.
- Крейвенська вторинка (реверс останніх 10%) відповідає тому, що Тесла емпірично виявляв ("верхні витки отримували пробій першими").

### Нове (не було явно в наших документах):
1. **Конкретний метод кроку намотки**: нижні 10 витків — 1" (25 мм) крок, верхні — 2.5" (63 мм) крок. Це вирішує проблему пробою.
2. **Крок первинної спіралі**: Тесла використовував рівнорозміщені витки без конічності.
3. **Метод тонкого налаштування**: переміщення відводу на первинній + додавання/знімання конденсаторних банок.
4. **Земля як вузол**: коли заземлення хороше, Земля виступає нульовим потенціалом (вузлом) для поверхневої хвилі — стримери уникають громовідводів.
5. **Iскровий проміжок**: роторний (1200 іскор/с) давав набагато кращий результат, ніж фіксований. Рекомендується для Етапу 2.

## 8. Рекомендації для Етапу 2 (на основі Colorado Springs Notes)

1. **Роторний іскровий розрядник** (≥800 іскор/с) замість фіксованого — значно покращує форму збудження.
2. **Крок намотки вторинки**: перші 10 витків від землі — щільний (1"), решта — розріджений (2–3" між витками). Наша конфігурація (Hs=570 мм, Ns=1600) відповідає.
3. **Заземлення**: труба 2 м, Ø16 мм + кокс + зволоження. Тесла підтвердив, що сухий ґрунт дає 2400 Ом — **недостатньо**. Цільовий опір <10 Ом.
4. **Extra-coil (магніфікатор)**: для відтворення Тесла-ефекту потрібна котушка ~Ø250 см, 95–106 витків, L ≈ 25–30 мГн. Для домашнього стенду — масштаб 1:3 (Ø83 см, 95 витків, L ≈ 3 мГн).
