# Energy-AI: Резонансна енергетика на принципах Тесла

Спільна дослідницька програма з резонансних та БТГ-систем за патентами Тесла, Капанадзе/Тюрка, з опорою на легітимну альтернативну фізику (SED — стохастична електродинаміка, ZPF, відкрита термодинаміка) та академічні роботи (Стрєбков, Денікольї, Джана, Крейвен).

**Статус:** Тиждень 1 з 12 — створення інфраструктури, теоретичних документів і протоколів.

---

## Філософія проєкту

Кожна гіпотеза — фальсифікаційна. Кожен експеримент має наперед сформульований критерій успіху/провалу. Негативні результати документуються нарівні з позитивними (їх не вистачає в спільноті БТГ — більшість ентузіастів про них мовчать).

Альтернативна фізика тут не означає "ігнорувати закон збереження енергії". Це означає:
- **SED (Stochastic Electrodynamics)** як математично сформульований "ефір" — рецензований, з державною підтримкою (DIA, NASA, Lockheed)
- **Відкрита термодинаміка** — система може мати COP > 1 щодо вхідної електричної потужності, якщо є вхід з іншого джерела (атмосферне E-поле, ZPF, тепло, геомагнетизм)
- **Перевірка стандартного ЕМ** до останнього — більшість заявлених ефектів пояснюється cos(φ), скін-ефектом, реактивною потужністю, помилками шунтів

## Метрологічні правила (читати перед кожним експериментом)

1. **Реактивна потужність ≠ активна.** В резонансі ВАр може бути в 100× більше Вт. Завжди обчислюй активну як `<v(t)·i(t)>` за період, не як `V_RMS · I_RMS`.
2. **Шунт перевіряй щоразу.** Кельвінівське (4-провід) вимірювання справжнього опору — нема одного "0.25 Ом" шунта в світі, який реально 0.25 Ом без перевірки.
3. **Калориметр — арбітр останньої інстанції.** Тепло не бреше. Якщо P_in < нагрівальний еквівалент в калориметрі — це аномалія, варта документації.
4. **DC мультиметр на пульсуючому сигналі бреше.** Тільки True RMS, тільки на діапазоні, що перекриває спектр сигналу.
5. **Сліпий аналіз для критичних експериментів.** Той, хто аналізує дані, не знає, в якій конфігурації (A/B/C) вони отримані. Маркування — рандомізоване.
6. **≥10 циклів для статистики.** Один прогон — не результат. Будь-який ефект має витримати рандомізацію порядку.
7. **Якщо бачиш COP > 1 — спочатку запідозри помилку вимірювання.** Систематично виключи кожне з 6 джерел вище. Тільки потім — фізику.

## Безпека

- Робота з ВВ (10–100 кВ) — **смертельна небезпека**.
- Ніколи в одиночку. Завжди з помічником, який знає першу допомогу і місце розрядної штанги.
- ВВ-перчатки 20 кВ + плексигласовий екран + розрядна штанга — мінімум.
- Конденсаторні банки розряджати кожен раз перед роботою — ВВ-конденсатори зберігають смертельну енергію годинами.
- Озон від іскрових розрядів отруйний — добра вентиляція.

## Як працювати з цим репо

- Кожен експеримент — окрема папка під `experiments/<NN>_<name>/` з:
  - `protocol.md` — методика і список вимірюваних величин
  - `results_YYYY-MM-DD.md` — звіт по конкретному прогону (гіпотеза → методика → дані → аналіз → висновок)
  - `raw/` — сирі CSV-дані з осцилографа (не комітити > 100 МБ)
- Кожна симуляція — окрема папка під `simulations/` з `.asc` (LTspice) або `.py` (Python) + `README.md`.
- Теоретичні документи — Markdown з LaTeX (inline `$E=mc^2$` та блочно `$$...$$`).
- Бібліографія — `references/bibliography.bib` (BibTeX).
- Локальний git — комітити після кожного значущого етапу. Без push на зовнішні сервери.
