# Калібрування вимірювальних інструментів — Етап 0 / Тиждень 1

**Призначення:** перевірити, що твоє існуюче обладнання дає правдиві цифри в RF-режимі **до того, як ми збудуємо хоч щось нове**. Без цієї перевірки 90% подальших результатів будуть під сумнівом.

**Критерій проходження:** еталонний резистивний нагрівач 100 Вт показує 100±2 Вт за всіма використовуваними методами вимірювання (ватметр, осцилограф+шунт, калориметр) одночасно.

## 2. Калібрування шунтів — 4-провідне (Кельвін)

**Що:** виміряти РЕАЛЬНИЙ опір кожного шунта, який буде використовуватися. Номінальне значення може відрізнятися на ±20%.

**Як:**
1. Підключи лабораторний DC-блок живлення з обмеженням струму до шунта.
2. Установи струм точно 1.000 A (контролюй за каліброваним амперметром в серії).
3. Виміряй падіння напруги на шунті 4-провідним методом (окремі провідники для струмового і вимірювального каналів — щоб виключити опір контактів).
4. R = V/I — це справжнє значення.

**Очікування для нашого проєкту:**
- Шунт 0.1 Ом — реальне значення зазвичай 0.095–0.110 Ом.
- Шунт 0.25 Ом — реальне 0.23–0.27 Ом.
- Шунт 1 Ом — реальне 0.97–1.05 Ом.
- Якщо різниця >10% від номіналу — не використовуй для COP-розрахунків.

**Записуємо:** реальне R, дату калібрування, температуру (опір металу залежить від T, +0.4%/°C для міді).

## 3. Калібрування мультиметра на пульсуючих сигналах

**Проблема:** середньостатистичний мультиметр на пульсуючому сигналі читає або пік, або середнє за модулем, або нічого правдоподібного. Фактор форми сигналу може дати помилку 3–10×.

**Тест:**
1. Генератор сигналів видає сигнал відомої форми (синус, прямокутник, пилкоподібний) і відомої RMS-амплітуди.
2. Виміряй мультиметром у режимі AC RMS.
3. Порівняй із розрахунковою RMS.

| Форма | Очікувана RMS (для амплітуди A) | True RMS показує | Помилка |
|-------|----------------------------------|------------------|---------|
| Синус | A/√2 = 0.707·A | | |
| Прямокутник | A | | |
| Пилкоподібний | A/√3 = 0.577·A | | |
| Імпульс 10% duty | A·√0.1 = 0.316·A | | |

Якщо мультиметр НЕ True RMS — він покаже одну й ту саму цифру для всіх форм. Це значить: на пульсуючих ВЧ-сигналах він НЕ ВИКОРИСТОВУЄТЬСЯ для розрахунку потужності. Ніколи.

## 4. Тест осцилограф + шунт = справжня активна потужність

**Це критичний тест.** Він підтверджує, що ми вміємо вимірювати P = ⟨v(t)·i(t)⟩ правильно.

**Стенд:**
1. Резистивний нагрівач 100 Вт (точна номінальна потужність на 220 В), розрахований на DC або AC 50 Гц. Краще використовувати спіраль на кераміці для стабільності опору.
2. Вимірюємо напругу на нагрівачі (CH1 осцилографа через ВВ-дифференц. щуп).
3. Вимірюємо струм через шунт у серії з нагрівачем (CH2 через токовий щуп або диференційний щуп на шунті).
4. Зберігаємо одночасний запис, ≥10 періодів, з частотою дискретизації ≥10× від частоти сигналу.

**Розрахунок (Python):**
```python
import numpy as np
# Завантаження CSV з осцилографа: t [s], v [V], i [A]
data = np.loadtxt('cal_50hz_100w.csv', delimiter=',', skiprows=1)
t, v, i = data[:,0], data[:,1], data[:,2]
P_inst = v * i                       # миттєва потужність
P_avg = np.mean(P_inst)              # активна (DC компонент P_inst)
S_avg = np.sqrt(np.mean(v**2)) * np.sqrt(np.mean(i**2))  # повна (RMS·RMS)
Q_avg = np.sqrt(S_avg**2 - P_avg**2)  # реактивна
cos_phi = P_avg / S_avg
print(f"P_активна = {P_avg:.2f} Вт")
print(f"S_повна = {S_avg:.2f} ВА")
print(f"Q_реактивна = {Q_avg:.2f} ВАр")
print(f"cos(φ) = {cos_phi:.3f}")
```

**Очікування:** для чисто резистивного навантаження P_avg = 100 Вт ± 2%, S = P (бо cos(φ) = 1, Q = 0).

Якщо P_avg ≠ 100 Вт ±2% — у нас проблема. Або фазова затримка щупів (компенсуємо), або несправний шунт, або сам нагрівач не 100 Вт (виміряти омметром і прорахувати V²/R).

**Перевірка повторюємо на:** 100 Вт DC, 100 Вт AC 50 Гц, далі — на ВЧ (див. п. 5).

## 5. Тест на ВЧ — як вимірювати на 50/100/200 кГц

Звичайні щупи й шунти можуть дати помилки на ВЧ через паразитні L і C, фазові затримки, скін-ефект.

**Стенд:**
1. Генератор RF сигналів (наприклад, function generator + RF підсилювач), що дає 10–50 Вт на 50 кГц у резистор 50 Ом.
2. Вимірюємо ту ж саму потужність двома методами:
   - Осцилограф + шунт (як у п. 4)
   - Калориметр (як описано в `calorimeter_protocol.md`)

**Очікування:** збіг ±5% між методами на 50 кГц. На 200 кГц допустимо ±10% (більше паразитів).

Якщо НЕ збігається — потрібна компенсація фазової затримки щупів. Параметри затримки записуємо у `experiments/00_metrology/probe_delays.md`.

## 6. Калібрування ВВ-дифференційного щупа

**Тест:** подати на вхід щупа точно відому ВВ (наприклад, від еталонного ВВ-генератора або з каліброваної середньоточкової подачі) і виміряти осцилографом. Перевірити коефіцієнт ділення (зазвичай 1:1000) і фазову затримку.

**Очікування:** коефіцієнт ділення збігається з паспортом ±2%. Фазова затримка <100 нс на 100 кГц.

---

## 7. Калібрування токового щупа Холла

**Тест:** пропустити через щуп точно відомий DC-струм (наприклад, від лабораторного джерела з каліброваним амперметром). Перевірити масштабний коефіцієнт.

**Окремий тест на AC:** подати синусоїдальний 1 А RMS на 50 Гц і 50 кГц, виміряти показання щупа. Перевірити, що значення збігається.
