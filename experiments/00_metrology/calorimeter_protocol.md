# Калориметричний протокол — фінальний арбітр енергобалансу

**Призначення:** мати незалежне вимірювання повної енергії, що поглинається навантаженням, незалежне від форми сигналу, частоти, фазового зсуву. **Тепло не бреше.** Якщо в калориметрі виділилось більше тепла, ніж пройшло через електричні шунти на вході — це справжня аномалія.

---

## 1. Конструкція

### 1.1 Базовий варіант ($30)
- **Посудина:** термос (термостакан з вакуумною ізоляцією, 1–2 л).
- **Робоче тіло:** дистильована вода, 1 кг (точно зважена).
- **Нагрівач:** заглиблений резистивний елемент (наприклад, ТЕН для електричного чайника на ~100 Вт), або у нашому випадку — електричне навантаження експерименту (резистор-навантаження TC). Контакти герметичні.
- **Термометр:** DS18B20 (точність ±0.0625°C, цифровий 1-Wire, $5).
- **Контролер:** ESP32 або Arduino Nano з 1-Wire бібліотекою. Зберігає T(t) у CSV з періодом 1 с.
- **Магнітна мішалка:** маленький мотор з магнітом + феритовий стрижень у воді (для рівномірного розподілу тепла) — $10.
- **Кришка:** ізолююча (пінопласт + плівка), з отворами для проводів і термометра, мінімальні теплові втрати.

### 1.2 Покращений варіант ($100)
- **Калориметр Дьюара** (виробничий, з каліброваною тепловою інерцією).
- **PT100 термометр** з 4-провідним підключенням (точність ±0.01°C).
- **Ampt-логгер** з частотою 10 Гц (для динамічних експериментів).

## 2. Калібрування

**Перед першим використанням** і **раз на місяць** під час активної роботи.

### Тест 1: Калібрування теплової інерції
Подаємо точно відомий потік тепла (DC через калібрований шунт до резистора в посудині), наприклад 100 Вт DC. Реєструємо T(t) протягом 10 хвилин.

Розраховуємо очікуваний приріст за теплоємністю води:
$$\Delta T_{calc} = \frac{P \cdot t}{m \cdot c_p}$$

де $c_p = 4186$ Дж/(кг·К) для води. Для P=100 Вт, t=600 с, m=1 кг:
$$\Delta T_{calc} = \frac{100 \cdot 600}{1 \cdot 4186} = 14.33\,°C$$

**Очікування:** реальний приріст $\Delta T_{exp} = 14.0\pm0.3\,°C$ (втрати в стінки термоса ~2%).

Якщо $\Delta T_{exp}$ значно відрізняється — або термос гірший, ніж очікуємо, або калібрування DC-джерела неточне.

### Тест 2: Калібрування втрат у середовище
Заливаємо воду на температурі +20°C відносно навколишньої. Без нагріву реєструємо T(t) протягом години.

Втрати тепла у середу:
$$\frac{dT}{dt} = -\frac{T - T_{amb}}{\tau}$$

де $\tau$ — теплова стала часу термоса (зазвичай 10–50 годин для якісного Dewar). Для нашого 10-хвилинного експерименту втрати <1% від нагріву на 14°C.

Записуємо $\tau$ для подальших корекцій.

## 3. Протокол вимірювання потужності експерименту

### Крок 1: Підготовка
1. Налити 1.000 кг (на точних терезах) дистильованої води в калориметр.
2. Початкова T₀ = T_amb (зрівноважено протягом 30 хв).
3. Включити мішалку, перевірити, що термометр стабільний.
4. Записати T₀ і час старту.

### Крок 2: Вимірювання
1. Включити експериментальну установку, навантаження якої — резистор у калориметрі.
2. Записувати:
   - T(t) кожну секунду (від ESP32)
   - V(t), I(t) на вході установки (осцилограф, як описано у `instrument_calibration.md`)
3. Тривалість: 10–15 хвилин для DT=10–15°C.

### Крок 3: Розрахунок
$$E_{calorim} = m \cdot c_p \cdot (T_{end} - T_0) + E_{losses}$$

де $E_{losses}$ обчислюється за тепловою сталою з калібрування.

$$\bar P_{thermal} = \frac{E_{calorim}}{t_{exp}}$$

Це РЕАЛЬНА середня потужність, що дисипує в навантаженні.

### Крок 4: Порівняння з електричним вимірюванням
$$\bar P_{electrical} = \frac{1}{t_{exp}} \int_0^{t_{exp}} v(t) \cdot i(t) \, dt$$

(обчислюємо у Python зі збереженого осцилограмою; див. `simulations/01_hairpin/process_oscillogram.py`).

**Очікування для будь-якого нормального пристрою:**
$$\bar P_{thermal} \le \bar P_{electrical}$$

(KPI ≤ 1: тепло — це лише частина енергії; решта в радіацію, акустичні втрати, заряд внутрішніх ємностей).

**Аномалія:**
$$\bar P_{thermal} > \bar P_{electrical} \cdot (1 + \text{похибки})$$

**Якщо це підтверджено в незалежних повторах — це публікаційний результат.**

---

## 4. Похибки і їх оцінка

| Джерело | Типова |
|---------|--------|
| Точність DS18B20 | ±0.0625°C → ±0.5% при ΔT=14°C |
| Точність маси води | ±1 г → ±0.1% |
| Втрати в середу за 10 хв | <1% з калібруванням |
| Розкид теплоємності c_p (T, мінерали) | <0.5% |
| Точність шунта (4-провід) | <1% (після калібрування) |
| Фаза щупів на ВЧ | <2% |

**Сумарна похибка калоричного методу:** ≤2–3%.
**Сумарна похибка електричного методу:** ≤5% на ВЧ.

**Аномалія повинна бути ≥10%** (3σ за обома методами), щоб не бути списаною на похибки.

---

## 5. Чому калориметр — арбітр

В RF-цепях складно точно відрізнити активну потужність від реактивної. Помилки cos(φ), скін-ефекту, паразитних L/C — все накладається. Калориметр обходить це повністю: незалежно від форми сигналу, **тільки активна (дисипована) потужність переходить у тепло**.

Якщо електричний метод каже "P_in = 80 Вт", а калориметр каже "поглинуто 100 Вт" — або електричний метод недооцінює (дуже часто), або є додаткове джерело (рідше).

**Приклад з історії:** Bedini SSG, MEG Бірдена, Капагена JLN — всі мали "перевагу" за електричним розрахунком; жоден не виявив надлишку при калориметричній перевірці. Це не означає, що калориметр — гарантія викриття. Це означає, що **без калориметру неможливо стверджувати COP > 1 надійно**.

## 6. Інтегрований Python-скрипт

Базовий аналізатор (буде у `simulations/01_hairpin/process_oscillogram.py`):
```python
def calorimeter_power(temperatures, times, mass_kg=1.0, cp=4186, tau_loss=36000):
    """
    P_thermal від DS18B20 + врахування втрат.
    """
    import numpy as np
    T = np.array(temperatures)
    t = np.array(times)
    dt = np.diff(t)
    # Корекція на втрати в середу
    T_amb = T[0]
    T_corrected = T + (T - T_amb) * dt[0] / tau_loss  # incremental
    # Потужність як похідна від енергії
    E = mass_kg * cp * (T_corrected - T_amb)
    P = np.gradient(E, t)
    return np.mean(P), np.std(P)
```

## 7. Безпека

- **Висока напруга в воді = смерть.** Якщо навантаження — ВВ-резистор, його контакти ГЕРМЕТИЧНІ, ізольовані. Краще: герметизація епоксидом.
- Заземлення калориметра (сам термос) — обов'язково при ВВ-роботі.
- **Контейнер вибухає при швидкому нагріві.** Не нагрівати воду вище 80°C — ризик пари, і втрати теплоємності зростають.
