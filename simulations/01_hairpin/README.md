# Stage 1 — Hairpin резонатор

Інструменти для проектування і моделювання Hairpin (ступа мідних шин Тесли).

## Файли

| Файл | Призначення |
|---|---|
| `hairpin_kraakman.cir` | SPICE-нетлист (для ngspice/LTspice, коли буде доступно) |
| `hairpin_sim.py` | Pure-Python симуляція з scipy (працює без ngspice) |
| `process_oscillogram.py` | Аналіз CSV-осцилограм (V·I → P_active, FFT) |
| `test_process_oscillogram.py` | 5 синтетичних тестових випадків з відомою наперед відповіддю |

## Швидкий старт

```bash
# 1. Перевірити, що аналізатор працює правильно
python3 simulations/01_hairpin/test_process_oscillogram.py

# 2. Передбачити очікувану частоту і амплітуду під твої параметри
python3 simulations/01_hairpin/hairpin_sim.py --c-mmc 150e-9 --l-bus 5e-6

# 3. Після прогону залізом — обробити CSV
python3 simulations/01_hairpin/process_oscillogram.py data/hairpin_<run_id>.csv \
    --probe-v 1000 --shunt 0.1
```

## Чому Python замість ngspice

На macOS Tier 3 (Homebrew) `ngspice` вимагає компіляції gcc-15 з джерел —
це години роботи. Лінійні RLC-задачі з простим іскровим розрядником
(гістерезисний switch) добре розв'язуються через scipy.solve_ivp за секунди,
тому ми не блокуємо проєкт на ngspice.

Коли ngspice буде встановлено — `hairpin_kraakman.cir` запуститься з
крупніших моделей (нелінійних трансформаторів, температурних залежностей)
для перехресної перевірки.

## Параметри за замовчуванням

| Парам. | Значення | Звідки |
|---|---|---|
| C_MMC | 150 нФ | 30× CDE 942C 4.7нФ паралельно |
| L_шин | 5 мкГн на гілку | мідь Ø22 мм, 220 см, U-форма |
| C_шин | 100 пФ | паразитна між гілками |
| V_NST | 21.2 кВ пік | NST 15 кВ RMS / 30 мА |
| V_розр_on | 8 кВ | пробій |
| V_розр_off | 1.5 кВ | гасіння |

При цих параметрах:
- f_res ≈ 130 кГц
- Q ≈ 200 (при R_шин = 50 мОм скін-ефект на ~130 кГц)
- E на іскру ≈ ½·150n·8000² ≈ 4.8 мДж
- Очікувана частота іскор: ~30 Гц (NST 30мА не встигає швидше)

Для Тесла-режиму 50 кГц збільшити C_MMC до ~1 мкФ. Для роботи в kHz Tesla coil
(Stage 2) потрібно перейти на topology з top-load.
